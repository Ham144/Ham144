### 💼 Featured Enterprise Projects (Pinned Repositories)

#### 🔄 [Approval Workflow Engine AI](https://github.com/Ham144/approval-workflow-engine-ai)
*   **What it is:** A dynamic multi-tenant approval system featuring a visual drag-and-drop workflow designer.
*   **Core Tech:** React Flow V11, React, Node.js, Active Directory (LDAP), Telegram Bot alerts, SMTP.
*   **Business Impact:** Replaces hardcoded business approval routing, enabling non-technical admins to map corporate routes with complex conditional jumps (e.g. if amount > $5k, route to CFO).

#### 📱 [Super POS Mobile](https://github.com/Ham144/super-pos-mobile)
*   **What it is:** An offline-first mobile Point of Sale app for sales reps and retail outlets.
*   **Core Tech:** React Native, Expo 52, NativeWind, TCP Sockets, Midtrans Payment Gateway.
*   **Business Impact:** Protects against field connectivity drops by caching sales locally and auto-syncing when online. Connects directly to local thermal printers via network sockets to print physical receipts on-the-go.

#### 🗺️ [Field Sales CRM (S-BIT)](https://github.com/Ham144/field-sales-crm-sbit)
*   **What it is:** A location-verified sales routing and client order-taking CRM.
*   **Core Tech:** React, Express.js, Leaflet Maps (GPS Auditing), Microsoft Dynamics NAV ERP integration.
*   **Business Impact:** Eliminates fake check-ins by recording GPS coordinates during visits, and automates order pushing directly to ERP using SOAP/NTLM web services.

#### 🗓️ [Warehouse Queue Management System](https://github.com/Ham144/warehouse-queue-management-system)
*   **What it is:** A real-time loading dock booking and Gantt board scheduler.
*   **Core Tech:** React, Node.js, WebSockets, drag-and-drop Gantt scheduling algorithms.
*   **Business Impact:** Prevents warehouse bottlenecking by coordinating supplier arrivals via a real-time drag-and-drop dashboard, resolving scheduling conflicts automatically.

#### 📦 [Inventory Audit System](https://github.com/Ham144/inventory-audit-system)
*   **What it is:** A robust stock auditing system designed for inventory counts, discrepancy reconciliation, and recount delegation.
*   **Core Tech:** React Router v7 (Remix framework), Tailwind CSS v4, Node.js, Express, MongoDB.
*   **Business Impact:** Streamlines physical stock verification processes, allowing audit managers to capture discrepancies and delegate recount tasks to specific staff in real-time.

#### 💰 [Petty Cash Manager](https://github.com/Ham144/petty-cash-manager)
*   **What it is:** Corporate expense tracking and petty cash logging system, featuring monthly budget limits and receipt upload auditing.
*   **Core Tech:** Next.js 15, NestJS v10, NextAuth, Chart.js/Recharts, Cloudflare R2/S3 receipt uploads.
*   **Business Impact:** Enforces financial compliance by monitoring department limits, visualizing budget burn rates, and maintaining audit trails of official digital receipts.
